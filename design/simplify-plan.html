Reminder notification

Code works · 5 tests pass
  • Shows today's guna and rounds, e.g. "ယနေ့ လောကဝိဒူ · ၅ ပတ် · သက်သက်လွတ်နေ့"
  • Mentions tomorrow's vegetarian day
  • Sets the next day's reminder
  • Stops when turned off
  • Comes back after the phone restarts
Real phones can differ

It may arrive some minutes late

Android delays reminders while the phone is idle. Fix: use exact timing when the phone allows it.

Some brands block it

Xiaomi, Oppo, Vivo, Realme, Huawei and some Samsung phones stop reminders for apps under battery saving. Fix: a one-time hint that opens the phone's battery setting for this app.
